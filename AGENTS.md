# Agent Instructions

## Local Server Commands

When the user says `start server` or `start app`, run:

```bash
./scripts/start-local-3004.sh
```

When the user says `stop server` or `stop app`, run:

```bash
./scripts/stop-local-3004.sh
```

Do not ask for clarification for these phrases unless the script fails.
